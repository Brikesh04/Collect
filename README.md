# Sunrise Bakery

A fictional bakery page built with plain Vite (vanilla JavaScript).

## Setup

```bash
npm install
```

## Local development

```bash
npm run dev
```

## Production build

```
Build command:   npm run build
Publish directory: dist
```

The built files will appear in the `dist/` folder.

## Preview the production build locally

```bash
npm run preview
```
